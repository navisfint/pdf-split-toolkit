# PDF 智能拆分工具

把一个几百页的扫描件卷宗，按卷内目录自动切成几十个独立 PDF，文件名带序号和题名。

**实测成果**：5 份真实档案卷宗（125~204 页），产出 **119 个 PDF / 781 页**，
逐个核对首页页码与目录声明，**吻合率 100%**。

带 PyQt 图形界面，PyInstaller 打成单文件 exe，双击即用，不装 Python。

---

## 一、这个问题的难点不在"切 PDF"

`PyPDF2` / `pypdf` 切分是三行代码。真正的难点是**搞清楚每一刀切在哪**：

| 难点 | 具体情况 |
|---|---|
| **零文字层** | 全部是 300dpi 扫描件（2480×3507），`textlen=0`，提不出任何文本，页码只能靠图像识别 |
| **页码位置不固定** | 有的在左下、有的居中、有的在右 |
| **一页两个数字** | 页脚可能同时有「第 X 页 共 Y 页」（证书自带）和档案连续页码，必须区分 |
| **前置页数不固定** | 封面 + 卷内目录的页数每卷不同（3~5 页），"物理页 → 档案页码"的偏移量不能写死 |
| **目录本身有错** | 登记重复、页码倒退、抄写串行，真实档案里都会出现 |
| **页面旋转** | 个别页 `rotation=180`，OCR 前得先归一化 |

## 二、技术路线

```
PDF ─┬─ 逐页渲染 ──→ 页码区域定位 ──→ 数字识别 ──→ 档案页码序列
     │                                              │
     └─ 目录页 OCR ──→ 条目解析 ──→ (序号, 题名, 声明页码)
                                                    │
                          前置页数自动探测 ←────────┘
                          （物理页 − 声明页码 = 偏移量，取众数）
                                                    │
                                                    ▼
                                    序号+题名 → 页码 → 物理区间 → 切分
```

关键设计：

**1. 前置页数自动探测，不写死**

```
档案页码 = 物理页序 − 前置页数
```

对每一页算出「物理页序 − 识别出的页码」，正常页的差值会稳定等于前置页数，
取众数即为该卷的偏移量。目录页和封底没有页码，自然被排除。

**2. 目录异常分两类处理，不"遇错即停"**

| 类型 | 判定 | 处理 |
|---|---|---|
| **重复登记** | 两条目录指向同一物理页 | 保留与正文内容匹配的那条，另一条跳过（文件名留空序号，便于对照） |
| **页码抄错** | 页码与前后条目不自洽（如倒退） | 按正文连续性推定正确页码，正常切出，文件名加 `_待核` |

重复登记的判断不只看页码——还要 OCR 该位置的正文标题去比对，
因为纸质目录抄错时，页码重复和内容错位经常同时出现。

**3. 双重校验**

- 每切完一份，重新打开产出 PDF，读出首页的页码，与目录声明值比对
- 覆盖率校验：产出的物理页区间之和应覆盖正文全程，缺口需报警

## 三、使用

### 图形界面

```
dist/PDF智能拆分.exe     双击运行
```

选 PDF → 自动预览识别结果 → 确认后切分。识别不确定的条目会标黄，可在界面上改。

### 命令行

```bash
python app_gui_qt.py              # Qt 界面
python core_split.py <pdf路径>     # 纯命令行切分
```

### 封皮追加工具

独立的第二个小工具（`append_cover.py`），给已有 PDF 批量追加统一封皮，
用于拆分产出后的归档整理。

## 四、性能

| 版本 | 5 份卷宗耗时 | 说明 |
|---|---|---|
| 初版（逐页全量渲染 + OCR） | 约 14 倍基准 | 准确但慢 |
| **快速版** | **1×** | 先定位页码区域再只识别该区域，问题行照标 `_待核` |

提速的关键是**不做全页 OCR**：页码位置有规律，先用图像特征把候选区域裁出来，
只对小区域做识别。准确率靠后续的连续性校验兜底，而不是靠提高单页识别精度。

## 五、目录

```
pdf-split-toolkit/
├── app_gui_qt.py           Qt 图形界面（推荐）
├── app_gui.py              Tk 图形界面（早期版本）
├── core_split.py           ★ 核心：页码识别 + 目录解析 + 切分
├── append_cover.py         封皮追加
├── append_cover_gui.py
├── build_exe.py            PyInstaller 打包
├── build_append_exe.py
├── 封皮追加工具.spec
├── docs/                   需求核对、拆分结果、exe 说明、封皮工具
└── scripts/                辅助脚本
```

`docs/01-需求确认与现状核对.md` 记录了开工前对真实 PDF 二进制的逐页核对——
其中纠正了需求描述里 3 处与实际不符的假设（页码是打印体不是手写、部分页有两个数字、
页码实际 100% 连续），这几处直接决定了技术路线和工期。
