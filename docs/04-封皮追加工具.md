# 04 · 封皮追加工具（附属程序）

> 撰写人：顾岩 ｜ 日期：2026-09-23
> 对应客户补充需求：拆分后，源 PDF 最后一页（牛皮纸「卷内备考表」）未被划入任何结果文件，
> 需补进**最后一个**拆分 PDF 的末尾。

---

## 一、要解决的问题

主程序按「卷内目录」拆分，目录里的条目覆盖不到**源 PDF 的最后一页**——
那一页是牛皮纸颜色的「卷内备考表」（封底性质），不含正文条目，所以被漏掉了。

```
源 PDF: [封面] [目录…] [正文 第1条] … [正文 第17条] [备考表] ← 这一页没进任何结果
                                              ↓
拆分结果: 001.pdf 002.pdf … 017.pdf   ← 备考表缺失
                                              ↓
补页后:   001.pdf 002.pdf … 017.pdf(末尾多了备考表)  ✅
```

## 二、做什么 / 不做什么

| | 说明 |
|---|---|
| ✅ 做 | 把源 PDF **最后一页**复制追加到结果文件夹里**编号最大**的 PDF 末尾 |
| ✅ 保留 | 源 PDF 原样不动；结果 PDF 其余内容不动 |
| ❌ 不动 | **主程序 `core_split.py` 一行没改**，本工具是独立的事后补页程序 |
| ❌ 不做 | 不重新拆分、不做 OCR、不判断哪一页是封皮（直接取末页） |

> 本工具**不依赖 OCR / PaddleOCR**，所以启动快、体积小。

## 三、配对规则（怎么找到对应关系）

主程序产出的目录结构是 `<输出目录>/<源PDF文件名>/001.pdf…`，
所以本工具用**子文件夹名 + `.pdf`** 去源 PDF 目录里找同名文件即可配对：

```
源 PDF 目录/                         拆分结果目录/
  DHGS-...-113.pdf          ←配对→    DHGS-...-113/
  DHGS-...-51.pdf           ←配对→    DHGS-...-51/
  …
```

若同名找不到，会退一步做**宽松匹配**（忽略空格、`-`、`_`、`·` 等符号差异，或互为前缀）。

## 四、使用方式

### 图形界面（推荐给非技术用户）

```
dist/封皮追加工具.exe        ← 双击运行
```
1. 「源 PDF 文件夹」选放**原始 PDF** 的目录
2. 「拆分结果文件夹」选**主程序输出**的目录（里面是各卷宗子文件夹）
3. 勾选项：
   - ☑ 改写前备份原文件（默认开）→ 生成 `017.bak.pdf`
   - ☐ 仅预览不写文件（试运行）→ 先看看会改哪些
4. 点「开始追加封皮」

### 命令行

```bash
python append_cover.py --src <源PDF目录> --out <拆分结果目录> [--dry-run] [--no-backup]
```
- `--dry-run` 只预览不写
- `--no-backup` 不生成 `.bak.pdf`（默认会备份）

## 五、安全设计

| 机制 | 说明 |
|---|---|
| **幂等保护** | 先比对目标 PDF **末页**与源 PDF 末页是否一致（页面尺寸 + 页内图像哈希）。一致就跳过，**重复运行不会插两遍**。 |
| **默认备份** | 改写前生成 `xxx.bak.pdf`（已存在则不覆盖） |
| **写临时文件** | 先写 `xxx.pdf.tmp` 再原子替换，中途失败不会留下半个坏文件 |
| **只动一个文件** | 每个结果文件夹里**只**改编号最大的那个 PDF，其余一律不碰 |

## 六、实测记录（113 号）

| 断言 | 结果 |
|---|---|
| 只改 `017.pdf`（5 → 6 页），其余 16 个文件页数不变 | ✅ |
| 追加的末页指纹 == 源 PDF 末页指纹 | ✅ |
| 重复运行不再插页（幂等） | ✅ |

目视确认：`017.pdf` 末页正是那张牛皮纸「卷内备考表」。

## 七、自己打包

```bash
python build_append_exe.py
```
产出 `dist/封皮追加工具.exe`。因不含 OCR 栈，体积远小于主程序。

> 打包策略与主程序一致：PySide6 只保留 `QtCore/QtGui/QtWidgets`，其余 Qt 模块排除；
> 并主动排除 `paddle/paddleocr/paddlex/scipy/skimage/cv2/numpy`（本工具用不到）。
> 注意：**不要**对 pymupdf 使用 `--copy-metadata`，本工具不走 PaddleX 依赖自检。
