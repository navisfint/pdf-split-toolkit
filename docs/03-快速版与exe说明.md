## 二、两个版本并存

| | 高精度版（提速后） | **快速版** |
|---|---|---|
| 入口脚本 | `scripts/split_main.py` | `scripts/split_fast.py` |
| 原理 | **自适应两轮抽样** + 分段 offset 拟合 + **每条目录行都做 OCR 锚点验证（带±3页窗口搜索）** | 抽样 12 页定 offset + 直接推算边界 |
| 五份耗时 | 见下方「提速整改」 | **约 2 分 47 秒（167 秒）** |
| 提速 | 相对旧慢版约 2 倍 | **≈ 14 倍** |
| 精度 | 最高 | 极高（119 条中 4 条 ±1 页） |
| 问题标注 | 有（记入报告） | **有**（记入报告） |
| 适用 | 出正式交付、逐条存疑时核对 | 批量快速处理、先出结果再抽查 |

**两版产出目录：**
- 高精度版 → `output/{卷宗名}/`
- 快速版 → `output_fast/{卷宗名}/`

### Exe 里两个模式都有，用勾选框切换

`dist/PDF智能拆分.exe` 界面上有「**快速模式**」勾选框，**默认勾选**：

| 勾选状态 | 实际跑的 | 对应脚本 |
|---|---|---|
| ☑ 勾上（默认） | 快速版（抽样12页） | 同 `split_fast.py` |
| ☐ 取消勾选 | **真·高精度版**（密集抽样 + 逐条 OCR 锚点验证） | 同 `split_main.py` |

> 注意：exe 的两种模式都由自包含核心 `core_split.py` 实现，逻辑已与
> `split_main.py` / `split_fast.py` 对齐（66 号实测：精确版与参考慢版逐条一致，
> 仅封面合并那一条按预期不同）。exe **没有** pnmap 查表加速，所以慢版每次都要真 OCR
> （一份约 20~30 分钟）；要更快就用快速模式，或直接用本地脚本 `split_main.py`（有 pnmap）。

## 二·补 · 2026-09-20 提速整改（慢版）

慢版原来「密集抽样 N//60」有严重冗余：125 页要抽 63 点，而其中绝大多数对
「确定 offset 分段」毫无贡献。整改三处：

| 改动 | 旧 | 新 | 收益 |
|---|---|---|---|
| 抽样策略 | 固定密抽样 `N//60`（125页→63点） | **自适应两轮**：稀疏 12~14 点定主 offset，仅在检测到 offset 跳变时对该区间加密 | 抽样 OCR 减少约 78% |
| 页码渲染 dpi | 200 | **120**（实测页码识别结果与 200dpi 完全一致，整页渲染省约 34%） | 每次页码 OCR 省 ~34% |
| 逐条锚点验证 | 保留 | **保留，一条不减**（±3页窗口搜索、ANCHOR_SHIFT / UNCONFIRMED 标记照旧） | 精度不降 |

> 新增函数：`adaptive_sample_pis()`（第一轮规划）、`refine_sample_pis()`（据观测结果二次加密）。
> 113 号实测：抽样点 63 → 14，全流程 17 个 PDF、0 待核。

**注意**：整份耗时的大头其实在**目录探测与解析的整页 OCR**（A4 大页整页识别），
抽样只占一部分；所以提速幅度不等于抽样缩减比例。要显著再快，需从整页 OCR 的
dpi / 页数下手（后续可做），当前以「不损精度」为前提。

## 三、快速版实测对比（五份样本）

| 卷宗 | 快版产出 | 慢版产出 | 快版总页 | 慢版总页 | 与慢版差异 |
|---|---|---|---|---|---|
| 51 | 53 | 53 | 201 | 198 | #001（+5 封面合并）、#028（3→1）|
| 60 | 16 | 16 | 186 | 183 | #001（+3 封面合并）、#011（6→5）、#016（18→19）|
| 66 | 17 | 17 | 154 | 151 | #001（+3 封面合并）|
| 67 | 16 | 16 | 131 | 128 | #001（+3 封面合并）|
| 113 | 17 | 17 | 123 | 121 | #001（+3 封面合并）、#012（12→11）|

- **文件数量 100% 一致**（119 个），重复登记行的判重结果完全一致。
- 除封面合并外，仅 **4 条**边界与慢版差 ±1 页 —— 这就是「放弃逐条纠错换速度」的代价。
- 51 号 #028：**快版反而是对的**（OCR 实测物理 111 = 页码 106，慢版锚点校验把它顶到了 112）。

**输出文件命名（2026-09-20 晚改）**：一律**纯编号** `001.pdf`、`002.pdf`…（按目录顺序，
不含标题、不含任何后缀）。有疑问的条目**不再体现在文件名上**，改为集中在
`拆分报告.md` 的「待核清单」里按序号列出，人工核对该序号即可。

## 四、封面 + 目录合并规则

首个拆分 PDF 的页范围由 `[原第1条起始页, 第1条结束页]` 扩展为 `[物理第1页, 第1条结束页]`，
即自动含入开头的封面和全部「卷内目录」页。

| 卷宗 | 前导页数 | 首个 PDF 变化 |
|---|---|---|
| 51 | 5 页（封面 + 4 页目录）| 6 → 11 页 |
| 60 / 66 | 3 页 | 12 → 15 页 |
| 67 / 113 | 3 页 | 6 → 9 页 |

> 开关：GUI 里勾选「把封面和目录并入第一个 PDF」；脚本用 `with_cover=True`。
> 若某卷宗开头不止封面+目录，前导页会全部并入首个 PDF。

## 五、Exe 使用方式

```
dist/PDF智能拆分.exe         ← 双击运行，无需安装 Python
```

**操作步骤**
1. 双击 `PDF智能拆分.exe`，打开图形界面。
2. 「PDF 所在文件夹」选放待拆分 PDF 的目录（可放多份）。
3. 「输出文件夹」选结果目录（默认在输入目录下建「拆分结果」）。
4. 勾选项：
   - ☑ 把封面和目录并入第一个 PDF（默认开）
   - ☑ 快速模式（默认开）—— 取消勾选则走**高精度逐条 OCR 校验**（慢，一份约 20~30 分钟）
5. 点「开始拆分」，日志区实时显示进度；完成后输出目录下会有：
   - `{原PDF名}/` 若干拆分好的 PDF
   - `拆分报告.md` 汇总表（含模式、待核清单）

**首次运行**：exe 自带 OCR 模型，第一次启动会解压（约 10~20 秒），之后正常。

## 六、自己打包 exe（换电脑/改代码后）

```bash
python build_exe.py
```

要点：
- 自动把 `~/.paddlex`（OCR 模型，177MB）复制到 `runtime/paddlex` 一并打进 exe。
- 用 `--onefile --noconsole`，加 `--collect-all paddle/paddleocr/paddlex/pymupdf/scipy/skimage`。
- **PySide6 不整包收集**：GUI 只用 `QtCore/QtGui/QtWidgets`，故显式排除 Qt3D / QtQml /
  QtQuick / QtWebEngine / QtMultimedia / QtCharts 等四十余个用不到的模块，
  体积由 608MB 降到约 300MB（详见 `build_exe.py` 里的 `--exclude-module` 清单）。
- 产出 `dist/PDF智能拆分.exe`（内含模型+Paddle 运行时+Qt）。
- 重新打包前先确认 `runtime/paddlex` 已存在（否则先跑一次让脚本自动复制）。

### ⚠️ GUI 为什么用 PySide6 而不是 tkinter

打包用的**隔离 Python（C:\Users\admin\.workbuddy\binaries\...）没有编译 tkinter**
（缺 `_tkinter.pyd`、tcl86t.dll/tk86t.dll、`Lib/tkinter`、`tcl/`），
用它打出来的 exe 双击会立刻报：

```
ModuleNotFoundError: No module named 'tkinter'
```

且因为 tkinter 是**编译进解释器**的，拷 3.11/3.12 的 `_tkinter.pyd` 过来也**不能用**（ABI 不匹配）。

故 GUI 改用纯 pip 可装的 **PySide6**（ABI 兼容 3.13 的 `abi3` 包），入口为
`app_gui_qt.py`。`app_gui.py`（tkinter 版）保留，仅在**带 tkinter 的 Python**里可用。

## 七、命令行用法（不用 GUI 时）

```bash
# 快速版（单份）
cd scripts
python split_fast.py 51 --out ../output_fast/DHGS-GL5•1•1•TJ6•5-51

# 快速版全流程（五份串行 + 计时）
python run_fast_all.py

# 高精度版（单份）
python split_main.py 67
```

参数：
- `--dry-run` 只推算不切分
- `--samples N` 抽样页数（快版默认 12）
- `--dpi N` 渲染 DPI（默认 200）
- `--out DIR` 指定输出目录
